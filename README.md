# JU$SO — The Oblivious Club

Static, responsive GitHub Pages website with four connected pages: entrance, inside club, backyard, and Street Dice.

## Included
- `index.html`, `club.html`, `backyard.html`, `game.html`
- `styles.css`, `game.js`
- `assets/` with the original Slow Burn promotional graphic and environmental crops based on the latest supplied red/blue four-screen mockup
- `previews/four-page-reference-mockup.jpg` — reference mockup preview, not a rendered browser screenshot

## Publish from iPhone
1. Download this ZIP and open it in the iPhone Files app. Tap the ZIP to extract it.
2. Open `github.com/JussoWrld/Oblivious-Club` and make sure you are on the `main` branch.
3. Upload the four HTML files, `styles.css`, `game.js`, `README.md`, and the complete `assets` folder to the repository root. Keep the folder and file names unchanged. The `previews` folder is optional.
4. Commit the upload to `main`.
5. In the repository, open **Settings → Pages** and verify publishing is set to `main` and `/(root)`.
6. Wait for GitHub Pages to finish, then check `https://jussowrld.github.io/Oblivious-Club/` on your phone.

## Art note
The included Slow Burn promotional graphic is the supplied `Neon Slow Burn Album Promo.png` and is used as provided. The environment image files are crops from the latest four-screen mockup, not newly generated standalone photographic artwork. They are included so the package is self-contained, but they are not a substitute for the full-resolution original scene artwork. The preview image is a mockup, not a browser screenshot.

## Game rules
Each round rolls two dice for the player and two for the house. Higher total earns 10 points and increases streak; ties earn 2 points and preserve streak; a loss earns no points and resets streak. There is no betting or real-money functionality.
