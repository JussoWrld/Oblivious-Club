JU$SO — THE OBLIVIOUS CLUB (GitHub Pages package)

CONTENTS
- index.html: responsive entrance, inside-club music/video area, backyard dice spot, game rules and links
- game.html: standalone playable Street Dice game
- assets/: original supplied club and Slow Burn artwork

UPLOAD FROM IPHONE
1. Extract this ZIP in the Files app.
2. Open https://github.com/JussoWrld/Oblivious-Club
3. For the safest review, create a new branch first (for example: website-preview). Upload index.html, game.html, README-GITHUB.txt, and the entire assets folder to the repository root. Keep the folder/file names unchanged.
4. Preview branches do not automatically replace your published main branch. To test safely, use GitHub's branch preview workflow or review files before merging. GitHub Pages usually publishes from the configured branch only.
5. Once reviewed, merge/upload the files to main (only when you are happy with the preview).

VIDEO READY — NO REBUILD REQUIRED
In index.html, find OFFICIAL_VIDEO_URL and OFFICIAL_VIDEO_FILE near the bottom.
- YouTube/Vimeo: set OFFICIAL_VIDEO_URL to the full video link and leave OFFICIAL_VIDEO_FILE as ''.
- MP4: upload the editor's MP4 to assets/slow-burn-official.mp4, set OFFICIAL_VIDEO_FILE to 'assets/slow-burn-official.mp4', and leave OFFICIAL_VIDEO_URL as ''.
The video area will use the official video instead of the temporary Instagram teaser. GitHub Pages has repository size/bandwidth limits, so a YouTube/Vimeo link is recommended for a full-length video.

IMPORTANT
This is a static site and needs no paid hosting or server. The home page navigation uses in-page links; the Street Dice buttons open game.html. Game scores are session-only and are not saved online. The visual follows the approved composition, but the supplied artwork does not include a real photo of the back wall/backyard; the backyard panel uses the existing supplied aerial image as its visual background rather than claiming it is a documentary photo of the rear. Test on iPhone before replacing the live site.
